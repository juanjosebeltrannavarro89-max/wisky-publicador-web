Política de Privacidad

Servicio: WISKY Publicador

Última actualización: 21 de octubre de 2026

1. Introducción

Esta política explica cómo WISKY Publicador trata la información relacionada con el uso de la aplicación y sus conexiones con plataformas de terceros.

2. Información tratada

Según las funciones que el usuario utilice, la aplicación puede procesar archivos de video seleccionados, títulos, descripciones, horarios de publicación, datos de configuración y credenciales o tokens de autorización necesarios para conectar cuentas de redes sociales.

3. Almacenamiento local

La aplicación está diseñada para guardar la cola de publicaciones y la configuración de las conexiones en el equipo del usuario. Las credenciales se almacenan mediante mecanismos de protección locales cuando están disponibles. El usuario debe mantener actualizado y protegido su equipo.

4. Conexión con plataformas externas

Cuando el usuario conecta una cuenta o solicita una publicación, los datos necesarios pueden transmitirse a la plataforma correspondiente, como TikTok, YouTube o Facebook. Estas plataformas procesan la información conforme a sus propias políticas de privacidad y condiciones.

5. Uso de la información

La información se utiliza para gestionar las conexiones autorizadas, preparar publicaciones, ejecutar las acciones solicitadas y mostrar el estado de las tareas. No se afirma que los datos nunca se transmitan: las transmisiones necesarias para las funciones solicitadas se realizan a través de los servicios conectados.

6. Compartición y venta de datos

WISKY Publicador no está diseñado para vender información personal. Los datos pueden transmitirse a las plataformas que el usuario conecta y a los servicios técnicos necesarios para ejecutar las funciones solicitadas.

7. Seguridad y conservación

Se emplean medidas de protección disponibles en el entorno de la aplicación. Ningún método puede garantizar seguridad absoluta. El usuario puede eliminar las conexiones y los datos locales mediante las opciones disponibles en la aplicación o retirando los datos correspondientes del equipo.

8. Derechos y solicitudes

Las solicitudes relacionadas con información personal pueden dirigirse al responsable del servicio mediante el contacto oficial que se publique en esta página. Las cuentas conectadas también pueden administrarse desde las plataformas correspondientes.

9. Cambios en esta política

Esta política puede actualizarse si cambian las funciones, las prácticas de tratamiento de datos o los requisitos legales. La fecha de actualización se modificará cuando se publique una nueva versión.

10. Contacto

Responsable del servicio: WISKY Publicador. Antes de publicar esta política, debe añadirse aquí una dirección de contacto válida para consultas sobre privacidad.
